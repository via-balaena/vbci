# Nutrient coverage

Generated by `cargo run -p balaena-warehouse -- coverage` from the datasets `sources.toml`
pins and the nutrients `nutrients.toml` lists; the test `the_coverage_report_is_current`
fails when this file differs from what that would write. Change the records, not this
file.

For each dataset: how many of its foods have a value for each nutrient, per 100 g
(`gold.nutrient_coverage`), and how many took it from each of the nutrient's USDA codes,
first choice first (`gold.nutrient_source`). Every food counts, meat included.
