# Ingredients

Generated by `cargo run -p balaena-warehouse -- ingredients` from `ingredients/` and the
datasets `sources.toml` pins; the test `the_ingredients_report_is_current` fails when this
file differs from what that would write. Change the records, not this file.

29 ingredients, with 45 forms. Each form is a state linked to one USDA food
(`gold.ingredient_form`); the first is the default, used when a recipe does not say. "Of
16" is how many of the nutrients `nutrients.toml` lists the food has a value for. FoodOn ids
come from USDA's data, which gives them for Foundation foods only. 4 alias
candidates (`gold.alias_candidate`) are names USDA's data gives a linked food that no
ingredient lists yet: unknown until a person reviews one into an ingredient's aliases. An
alias of two or more words whose last word is a count unit's name
(`gold.ingredient_alias_unit`) is shown with that unit: a recipe line that uses it with no
unit, such as `@garlic cloves{2}`, counts in it.

Each ingredient's organism (`gold.ingredient_organism`) is an NCBI Taxonomy id read from one
place: the "NCBI Taxon" USDA's data gives a Foundation food, for 18 ingredients; a
Wikidata item `sources.toml` pins, for 5; or none, saying why, for 6.

What each ingredient is made from (`gold.ingredient_origin`): nothing, as it is harvested, for
13; other ingredients (`gold.ingredient_made_from`), for 5; or something that
is no ingredient, saying why, for 11. A crop yields only a harvested ingredient.
