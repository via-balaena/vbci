# Diet status

Generated by `cargo run -p balaena-warehouse -- diet` from the datasets `sources.toml` pins
and the records in `diet/`; the test `the_diet_report_is_current` fails when this file
differs from what that would write. Change the records, not this file.

Each food's answer for each diet, yes, no or unknown (`gold.food_diet`), and what decided
it, the first that applies: an exception for the food (`diet/exceptions.toml`), a naming
rule within its category (`diet/rules.toml`), the animal organism a Foundation food
records (`diet/taxa.toml`), or its category's class (`diet/categories.toml`). Vegan is The
Vegan Society's definition and vegetarian the Vegetarian Society's criteria
(`docs/architecture.md`, "Decided"). An answer that came from a category holds for a
food only as far as its USDA name shows what is in it.
