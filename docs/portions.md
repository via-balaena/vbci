# Portions

Generated by `cargo run -p balaena-warehouse -- portions` from the datasets `sources.toml`
pins and `units/count.toml`; the test `the_portions_report_is_current` fails when this file
differs from what that would write. Change the records, not this file.

USDA's portions give the grams in an amount of a unit (`silver.usda_portion`). Each
portion's unit is read from its text (`silver.usda_portion_unit`): the longest run of its
leading phrase's first words that is a mass or volume unit cooklang knows, or a count unit
`units/count.toml` lists. A portion no unit reads is listed below by its leading phrase,
not guessed.
